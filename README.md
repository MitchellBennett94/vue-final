# Lookbook Library

## Overview
Lookbook Library is a community-driven online platform for buying and selling used books. The website provides a user-friendly interface to browse books by genre, list books for sale, and explore featured books.

## Features
- **Navigation Bar**: Includes links to browse used books, genres, and a counter for listed books.
- **Background Design**: A bookshelves-themed background image on the sides for aesthetic appeal.
- **Icons**: Small circular icons added to enhance the navigation links.
- **Responsive Design**: Ensures the website looks great on all devices.

## How to Run
1. Clone the repository or download the project files.
2. Open `index.html` in any modern web browser.
